3. Follow installation wizard

```
└── Report Title
```

## 📊 Usage Workflow

### Daily Operations
1. **Login** with cashier/admin credentials
2. **Set Opening Balance** for the day
3. **Record Sales** throughout the day
4. **Add Expenses** with descriptions and amounts
5. **Close Balance** at end of day
6. **Print Receipt** for records
7. **Review Discrepancies** if any

### Administrative Tasks
- **User Management**: Add/remove cashiers
- **Data Export**: Generate CSV reports
- **Backup Management**: Schedule automatic backups
- **System Configuration**: Adjust settings as needed

## 🔍 Troubleshooting

### Installation Issues
- Run installer as Administrator
- Temporarily disable antivirus
- Ensure .NET Framework 4.7.2+ installed

### Performance Issues
- Close unnecessary applications
- Increase virtual memory
- Run disk cleanup
- Check for Windows updates

### Printing Problems
- Verify printer installation
- Check printer permissions
- Update printer drivers
- Test with Print Preview
