# Mini Mercado Balance Closing System v2.0.0

## 🚀 Release Notes

### What's New in v2.0.0

#### ✨ New Features
- **Enhanced Report Printing**: Receipts now include detailed expense lists with item descriptions and amounts
- **Comprehensive Settings System**: Full business configuration with multiple languages support
- **Improved Receipt Formatting**: Professional business header with contact information and tax ID
- **Business Intelligence**: Advanced KPI display and chart customization options
- **Multi-language Support**: Interface available in English, Spanish, Portuguese, French, German, Italian, Arabic, Chinese, Japanese, and Korean
- **Theme System**: Modern Material 3 design with dark/light mode support

#### 🛠️ Technical Improvements
- **Database Enhancements**: Fixed expenses tracking and retrieval for accurate report generation
- **Performance Optimizations**: Improved UI responsiveness and reduced memory usage
- **Code Quality**: Addressed linting issues and improved maintainability
- **Settings Persistence**: All configurations are saved and restored between sessions

#### 🐛 Bug Fixes
- Fixed expense details not appearing in printed reports
- Resolved database record ID handling for expense tracking
- Fixed UI navigation and removed unnecessary demo components
- Corrected settings screen layout and responsiveness

#### 🔧 Settings & Configuration
- **Business Information**: Name, address, phone, email, website, tax ID
- **Currency & Financial**: Currency selection, tax rates, decimal places
- **Receipt & Report**: Custom headers, footers, paper sizes, print quality
- **System Preferences**: Date/time formats, themes, auto-save intervals
- **User Management**: Role-based access, password policies, session timeouts
- **Security**: Audit trails, data encryption, session logging
- **Data Management**: Auto-backup, retention policies, export formats
- **Business Intelligence**: Dashboard customization, chart preferences, KPI displays

### 📦 Installation Options

#### Option 1: Installer (Recommended)
1. Download `MiniMercadoBalanceSetup.exe`
2. Run the installer as Administrator
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

#### Option 2: Portable Version
1. Download and extract the `portable` folder
2. Run `salaries_app.exe` directly
3. No installation required - runs from any location
