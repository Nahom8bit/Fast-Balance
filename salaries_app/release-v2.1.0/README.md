## 📦 Release Contents

This release includes:

1. **MiniMercadoBalanceSetup.exe** - Windows Installer (Recommended)
2. **portable/** - Standalone executable (No installation required)

## 🔧 Installation Options

### Option 1: Windows Installer (Recommended)
1. Download `MiniMercadoBalanceSetup.exe`
2. Run the installer as Administrator
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

### Option 2: Portable Version
1. Download and extract the `portable` folder
2. Double-click `RUN_MINI_MERCADO.bat` or `salaries_app.exe`
3. No installation required - runs directly

## 📋 System Requirements

- **OS**: Windows 10/11 (64-bit)
- **RAM**: 4GB minimum, 8GB recommended
- **Storage**: 100MB available space
- **Permissions**: Administrator rights for first run

## 📊 Features

- 💰 **Daily Balance Closing**: Streamlined cash reconciliation workflow
- 📈 **KPI Dashboard**: Real-time analytics and performance metrics  
- 👥 **User Management**: Role-based access for cashiers and administrators
- 🧾 **Receipt Printing**: Generate and print closing receipts
- 📄 **Data Export**: Export reports to CSV and PDF formats
- 🔐 **Secure Authentication**: User login with role permissions
- 💱 **Kwanza Currency**: Native support for Angolan Kwanza (Kz)

## 🛠️ Troubleshooting

**Application won't start:**
- Run as Administrator
- Check Windows Defender exclusions
- Verify all files are in the same folder (portable version)

**Data not saving:**
- Ensure write permissions to application folder
- Check available disk space
